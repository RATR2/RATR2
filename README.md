## Working on now

**[FissionMC](https://github.com/FissionMC/FissionMC)** is a Minecraft server in Kotlin that splits one world across several backend servers behind a master, with seamless crossings between them. Currently: borders, handover and mob behaviour at region edges, and testing with four backends at once.
